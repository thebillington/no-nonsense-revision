Try the kind of questions you will meet

Six questions from across both papers. Open a question to reveal the answer and the explanation behind it.

Computer systems · Architecture of the CPU Which stage of the fetch-execute cycle works out what an instruction means? Show answer
  1. Store
  2. Execute
  3. DecodeCorrect
  4. Fetch

Why: The fetch-execute cycle has three stages: fetch the next instruction from memory, decode it to work out what it means, and execute it.

Computer systems · Primary storage (memory) Which type of memory loses its contents when power is removed? Show answer
  1. Non-volatile memory
  2. Volatile memoryCorrect
  3. Secondary storage
  4. ROM

Why: Volatile memory loses its contents when the computer is switched off. RAM is the main example.

Computer systems · Networks and topologies A bank links its offices on three continents. Which type of network is this? Show answer
  1. A star network with one central switch
  2. A local area network on a single site
  3. A peer-to-peer network of two computers
  4. A wide area network, linking distant sitesCorrect

Why: A local area network covers a single site, such as a school, while a wide area network spans a large geographical area, such as branches across a country.

Computer systems · Threats to computer systems and networks Which describes malware? Show answer
  1. A rule that controls who may use a network
  2. Software written to harm, disrupt or steal dataCorrect
  3. Hardware that connects a computer to a network
  4. Software that keeps a computer's files tidy

Why: Malware is software designed to cause harm, disrupt a system or steal data. Viruses, trojans, spyware, keyloggers, adware and ransomware are all forms of malware.

Computational thinking, algorithms and programming · Designing, creating and refining algorithms A student draws an algorithm as symbols joined by arrows. What has the student produced? Show answer
  1. A structure diagram
  2. A trace table
  3. A flowchartCorrect
  4. Pseudocode

Why: A flowchart represents an algorithm as a diagram of standard symbols joined by arrows, so the order of the steps can be seen.

Computational thinking, algorithms and programming · Boolean logic A warning light comes on only when both sensors detect movement. Which gate does the circuit need? Show answer
  1. An AND gate, because both inputs must be 1Correct
  2. A NOT gate, because it inverts its one input
  3. An OR gate, because one input being 1 is enough
  4. No gate, because the sensors already send a digital signal

Why: An AND gate outputs 1 only when all of its inputs are 1, and outputs 0 for every other combination of inputs.
